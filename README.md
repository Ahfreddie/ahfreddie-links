# ahfreddie-links
A personal hub for links to all my platforms alternative to linktree

## Project brief
Ok so this small project is a result of me trying to build something on my own instead of using an external service that requires a subscription. 

I was setting up a linktree and then I got annoyed by the fact customization is hidden behind a paywall and after a research the best option is to just build my own, even though for now it is just simple and doesn't have a lot of functionality but it will get the job done that is connecting people to my different platforms.

Anyway I also plan to practice tailwind with this, an awesome learning moment indeed.
